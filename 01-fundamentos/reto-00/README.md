# Reto #00 — Sintaxis, variables y tipos de datos

## Objetivo

Introducir los fundamentos de Python mediante la utilización de comentarios, variables, constantes, tipos de datos y salida por terminal.

## Conceptos aplicados

- Comentarios de una línea mediante `#`.
- Cadenas multilínea mediante triple comilla.
- Variables y convenciones para constantes.
- Tipos de datos: `str`, `int`, `float` y `bool`.
- Funciones `print()` y `type()`.

## Implementación

Archivo principal: `main.py`.

Se implementaron diferentes variables para representar información de distintos tipos de datos y se utilizaron funciones para identificar sus tipos e imprimir un mensaje en terminal.

## Aprendizajes

- Python utiliza tipado dinámico.
- Los nombres de variables hacen referencia a objetos.
- Las constantes se representan convencionalmente con nombres en mayúsculas.
- `#` permite introducir comentarios.
- Las cadenas multilínea no son comentarios propiamente dichos.
- `print()` permite mostrar información y `type()` permite identificar el tipo de un objeto.
